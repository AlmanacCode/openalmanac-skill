# OpenAlmanac Skill

Agent skill for [OpenAlmanac](https://openalmanac.org) — the open knowledge base.

## Install

```bash
npx -y skills add AlmanacCode/openalmanac-skill -y
```

Your coding agent (Claude Code, Cursor, Codex, Windsurf, etc.) learns how to read, write, and edit Almanac articles. One command — works across sessions.

## What it does

Once installed, your agent can:

- Search and read existing articles
- Research topics using web search
- Write new articles with proper citations
- Edit and improve existing articles
- Manage version history
